# AI Study Buddy

Personalized study assistant using Xiaomi MiMo for flashcard generation, quiz creation, and concept explanation

## 🎯 Features

- Powered by Xiaomi MiMo API
- Simple and intuitive interface
- Real-time processing

## 🚀 Quick Start

```bash
git clone https://github.com/mail-eth/ai-study-buddy.git
cd ai-study-buddy
npm install
cp .env.example .env
# Add your MIMO_API_KEY
npm start
```

## 📊 Use Case

This project demonstrates practical AI integration using Xiaomi MiMo API for real-world applications.

## 🛠️ Tech Stack

- Xiaomi MiMo API
- Node.js
- Express
- Simple HTML/CSS frontend
